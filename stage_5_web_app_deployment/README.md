# GIAI ĐOẠN 5: Hệ thống Web App Streamlit Chuẩn FinTech SaaS (`stage_5_web_app_deployment`)

## 1. Mục tiêu Giai đoạn 5
1. Xây dựng ứng dụng Web **`FinAudit AI — FinForensics`** trên nền tảng `Streamlit` với giao diện **FinTech SaaS chuyên nghiệp**, bảng màu hài hòa (`Slate Navy #0F172A`, `Royal Blue #1E40AF`, `Emerald #059669`, `Amber #D97706`, `Crimson #DC2626`).
2. Tích hợp đầy đủ **5 Phân hệ Chức năng thực tế**:
   - **Phân hệ 1:** *Tổng quan Thị trường & Quét Rủi ro Ngành ICB (Market & Sector Radar)*
   - **Phân hệ 2:** *Hồ sơ Pháp chứng Doanh nghiệp 360° & Giải thích AI (SHAP Waterfall)*
   - **Phân hệ 3:** *Phòng Thẩm định BCTC Mới (Upload CSV/Excel & Chấm điểm Trực tiếp)*
   - **Phân hệ 4:** *Trợ lý AI Soi Thuyết minh PDF & Tra cứu Chuẩn mực VAS/VSA 240 (Grounded Hybrid RAG)*
   - **Phân hệ 5:** *Trung tâm Kiểm chứng Mô hình & Xuất Hồ sơ Kiểm toán (HTML/PDF/CSV Export)*
3. Kiểm thử hiệu năng thực tế trên máy RAM 32GB và xuất báo cáo nghiệm thu [`REPORT_STAGE_5_SYSTEM_DEPLOYMENT.md`](REPORT_STAGE_5_SYSTEM_DEPLOYMENT.md).

## 2. Cách Khởi động Web App
```powershell
streamlit run stage_5_web_app_deployment/app.py
```
